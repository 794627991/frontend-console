# 功能测试矩阵（全功能提炼 · 待决策版）

> 用途：把整个工具的功能面摊开，供用户勾选「哪些先测/哪些不测」，再按勾选结果细化用例与脚本。
> 现状：自动化用例约 100 条（L0-L3），但覆盖集中在 harness/VCS/编辑器主路径；下表列出**全部功能点约 150 个**，已覆盖约 55，缺口约 95。

## 图例

- 优先级建议：**P0** 核心/高频（优先补）；**P1** 重要但低频；**P2** 边缘/可延后。
- 自动化方式：`H` = headless 可自动化；`R` = 需真实窗口（真机链路/桌面交互）；`M` = 手工（构造复杂）；`N` = 需网络/设备。
- 覆盖：✅ 已有自动化用例；◐ 部分覆盖；— 未覆盖。
