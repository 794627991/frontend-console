# 前端控制台 使用说明（README）

> 一句话：这是一个给**嵌入式/串口调试**用的多功能工具箱——串口、SSH、Telnet 终端 + 日志分析 + 文件编辑对比 + 计算器 + TFTP 传输 + Claude AI 助手，全部装在一个窗口里。
>
> 如果你刚拿到这个工具，**只需要看「快速上手」一节**就能开始用。

## 功能全景

| 模块 | 一句话 |
|------|--------|
| 终端 | 串口 / SSH / Telnet 多标签，复制粘贴/查找/时间戳全套 |
| 日志 | 自动记录、日志库秒开 G 级文件、对比、回放 |
| 文件 | 编辑器 / MD 预览 / Hex / 双栏 diff / 文件树 / 笔记 |
| 计算器 | 程序员位编辑 + 表达式 + 时间戳换算 + 文件哈希 |
| 传输 | TFTP + HTTP 双通道和设备互传固件/日志 |
| **Claude Harness** | 微信式 AI 聊天界面，让 Claude 帮你操作串口、分析日志、改文件 |
| Claude Proxy | 内网流量管家：限流重试 + 上下文压缩 + 额度看板 |

---

## 一、快速上手（3 步开始）

1. **打开工具**：双击「前端控制台」快捷方式（或 `前端控制台.exe`）。
2. **连接设备**：点顶栏「＋ 新建连接」→ 选「串口 / SSH / Telnet」→ 填地址后点「连接」。连上后会自动开一个终端标签页，直接敲命令即可。
3. **想不到了就开设置**：左上角 Claude 图标（自绘星形标志）打开设置，**最底部「帮助」**分区是完整使用手册。

---

## 二、连接设备（串口 / SSH / Telnet）

点「＋ 新建连接」弹窗里选一种：

| 类型 | 要填什么 | 说明 |
|------|---------|------|
| **串口** | 端口、波特率 | 界面里列出本机能看到的串口；115200 等常用波特率可选 |
| **SSH** | 主机、端口、用户名、密码或密钥 | 设备常用 SSH（22 端口），支持密钥文件登录 |
| **Telnet** | 主机、端口（默认 23） | 设备侧 telnet 服务须已开启；很多设备只支持一个会话，你连着别人就进不来，这是设备限制 |

- **可以同时开多个连接**：每个连接一个标签页，互不干扰。
- 断线自动重连（指数退避），重连过程终端里会显示。
- 左侧栏「**最近**」自动记住你连过的设备，点击直接重连（密码也会记住）。
- 左侧栏「**打开**」列表显示当前连接，点可切换，✕ 断开。

### 终端里的常用操作

| 想做什么 | 怎么做 |
|---------|--------|
| 复制 | 鼠标选中文字 → `Ctrl+C`（无选中时 `Ctrl+C` 是发中断信号 ^C） |
| 粘贴 | `Ctrl+V`；或 `Shift+右键`（PuTTY 习惯）。**任何程序里复制的内容都能贴进来** |
| 右键菜单 | `Ctrl+右键` 弹菜单（复制全部 / 粘贴 / 查找 / 清屏）。可在 设置→终端设置 里改成"右键直接弹菜单"或"右键直接粘贴" |
| 查找 | `Ctrl+F`，高亮跳转 + 全部命中列表 |
| 调字号 | `Ctrl + =` 放大，`Ctrl + -` 缩小，`Ctrl + 0` 恢复默认 |
| 清屏 | 工具栏「⊘ 清屏」（历史缓冲不丢，只清显示） |
| 发中断 | 工具栏「^C」按钮，或直接 `Ctrl+C` |
| 时间戳 | 工具栏「⏱ 时间戳」：新输出行首加时间，方便定位问题 |
| 新日志 | 工具栏「＋📋 新日志」：从现在起另存一个日志文件 |

> 多行粘贴（比如整段配置）会先弹确认框，防止误把大段文字灌进设备。

### 命令库（右侧面板「⌘ 命令」）

把常用命令保存起来一键发送，跨设备通用。可加备注名，点条目即发送到当前连接。

## 三、日志（自动记录 + 分析）

- **自动记录**：每个连接的输出自动存成日志文件（工具目录 `serial_logs/`），不占你操作。
- 顶栏「**📜 日志库**」：查看全部日志，按大小/时间排序，可搜索、跳转、过滤。**G 级大日志也能秒开**。
- **日志对比**：选两份日志（比如正常机器 vs 异常机器的启动日志）做差异对比，定位问题利器。
- **回放**：终端输出可录制/回放，时序重现（右侧面板）。
- 右侧面板「**● 感知**」「**📊 分析**」：实时看连接输出、分析设备状态。

## 四、文件功能

| 功能 | 入口 | 说明 |
|------|------|------|
| **打开文件** | 顶栏「📂 打开」或直接拖进窗口 | 自动识别：文本→编辑器，超大日志→查看器，二进制→Hex 查看器 |
| **新建笔记** | 顶栏「✎ 新建笔记」 | 轻量文本笔记，保存到工具目录 `files/`；「📝 笔记」列表可随时打开 |
| **文件对比** | 顶栏「🔀 对比」 | 双栏 diff（和 VSCode 一样），文本/二进制都行；也可以右键文件标签页选两份对比 |
| **文本编辑器** | 打开文本文件 | 语法高亮、C/JSON 大纲树；小于 20MB 可编辑，超大自动转只读查看 |
| **MD 预览** | 打开 .md 文件 | 左源码右预览分栏，**两边滚动实时同步**（在哪边翻都跟手）；代码高亮、图片显示 |
| **Hex 查看器** | 打开 .bin 等二进制 | 16 进制查看/编辑，多类型检视（整数/浮点/大小端），Intel HEX 解析回写 |
| **文件树** | 左侧栏「文件树」 | 添加文件夹作工作区，点击文件直接打开；支持拖文件夹进来 |
| **文件关联** | 设置 → 文件关联 | 接管 txt/log/md 等后缀的双击打开；接管后双击文件**全屏**打开本工具 |

## 五、程序员计算器

顶栏「🧮 计算器」：

- **寄存器位编辑**：8/16/32/64 位，逐位点击翻转，HEX/DEC/OCT/BIN 四进制实时联动。
- **位运算**：AND/OR/XOR/NOT/移位，带操作数框。
- **表达式**：`(0x1F << 2) | 0b101` 直接算，支持括号和 0x/0b/0o 前缀。
- **点按键盘**：鼠标点按钮即可输入表达式，两种模式切换——
  - **HEX 程序员**：A–F 字母、`& | ^ ~ << >>` 位运算，整数域（结果联动位格/四进制）；
  - **DEC 科学**：小数点 `.`、`^` 乘方、`sqrt/log/ln` 函数，小数域（如 `3.5*1.2+sqrt(2)`）。
  公共键：`CE` 清空、`⌫` 退格、`( )` 括号、`=` 计算。
- **计算历史**：每次按 = 自动记录，点击历史条目直接回填重算，关工具再开也还在。
- **时间戳换算**：贴入 Unix 秒/毫秒/0x 时间戳 → 本地时间/UTC/相对时间/HEX 一键看全；点「现在」取当前时间戳；反向选日期时间 → 秒/毫秒/HEX 三形态，点值即复制。
- **字节序 Swap**：大小端一键互换。
- **文件哈希**：拖入或选择任意文件，一次算出 MD5/SHA1/SHA256/SHA512/CRC32，点哈希值即复制——校验固件/文件完整性用。

## 六、TFTP / HTTP 文件传输（左侧栏「TFTP/HFS」）

和设备互传固件/日志的快车道，UDP 69（TFTP）+ TCP 8081（HTTP 下载）双通道，**共用同一个目录**：

- **设置目录**：面板里填路径回车（或点 📂 选目录）。切过的目录会被**记住为默认**，下次启动自动回到这里；目录被删/移动才回退桌面。
- **设备拉文件**：设备端 `tftp -g -r 固件.bin <PC的IP>`——从 TFTP 目录下发。
- **设备推文件**：设备端 `tftp -p -l 抓包.log <PC的IP>`——上传到 TFTP 目录。
- **HTTP 下载**：浏览器/wget 访问 `http://<PC的IP>:8081/<文件名>`，大文件走 HTTP 更快。
- **传输记录**：每次收发都有记录（方向/文件/对端/进度/结果），最近 20 条。

> Windows 防火墙首次可能弹窗，选「允许访问」（局域网设备要能连进来）。

## 七、Claude Harness（AI 聊天会话）★ 重点

Harness 是给 Claude Code 套的**微信式聊天界面**——左边会话列表、右边消息流、底部输入框。你像用微信一样和 Claude 聊，它在后台帮你操作串口、分析日志、改文件。顶栏「Claude」按钮即可进入。

### 7.1 会话管理

- **多会话并行**：左侧「＋ 新建会话」开新会话；每个会话独立上下文、独立项目目录、独立模型，互不干扰。
- **会话卡片**：显示项目名、标题、相对时间、当前模型（多模态模型带 👁 标记）；回复中有 ● 呼吸点。
- **来回切换，内容一个不少**：A 切到 B 再切回 A（哪怕 A 还在回复中），消息、思考、工具调用、执行动画**完整恢复**并自动回到底部继续跟读——运行中的会话切走再回来，不会出现「中间什么都没有了」。
- **切回历史会话**：上下文完整恢复（消息、思考、工具调用全都在）；点开过的思考段/工具抽屉切回来**保持展开且有内容**。
- **中断有痕迹，重开也在**：打断正在进行的回复，该回合会收拢并标上「已停止」；**关闭工具重新打开后依然能看到**这批中断痕迹，不会无痕消失。
- **会话太多**：顶部搜索框按标题/项目过滤；✕ 删除（Claude 侧记录保留）；✎ 重命名。
- **15 分钟空闲自动回收**后台进程，下次发消息自动复活续上下文，无感。
- **新建会话 = 无工程状态**：不继承上一个会话的项目目录；要指定项目点输入卡顶部的「📁 项目」。

### 7.2 发消息与队列（可靠性）

- **附件**：📎 加图片/文件，或直接**粘贴截图**、**拖文件进窗口**；图片会走多模态或识图（见 7.4）。
- **@ 引用**：输入 `@` 弹文件选择器，把项目内文件引用给 AI。
- **回复中继续输入 = 自动排队**：AI 回复没结束也能连发，消息进排队条（输入框上方），结束自动依序发出。
  - **绝不静默丢失**：队列由后台泵定时对账驱动——轮到它时正好在回复中就 3 秒后重试，进程恰好被回收就自动复活再发，失败自动重试；持续失败（如超窗类硬拒绝）会**标红提示**而不是永远挂起。
  - **⬆ 立即发送**：打断当前回复插队发这条；进程刚死也会先复活再发，点了必有响应。
  - **✎ 编辑 / 🗑 丢弃**：编辑放回输入框、删除即彻底移除——被编辑/删除的消息**不会复活**又被发出去。
  - **最左边的 ⠿ 是抓手，按住上下拖可调发送顺序**；
  - 排队条顶起/收起时，正在底部跟读的你会自动跟着滚，不用手动翻页。
- **⚡ 技能**：选择已装技能（如 pdf、docx 处理）随消息发给 Claude。
- **🧠 思考**：切换思考档位（关闭/low/medium/high/max），复杂问题开高档更稳。
- **🤖 自动执行**：控制工具调用的自动化程度（每步确认/自动执行）。

### 7.3 消息流阅读

- **粘底跟读**：AI 正在回复时自动跟随滚动到底部，新内容出了立即看得到；**你往上翻历史时不会被强行拽回**，翻完停在底部附近会自动恢复跟读。
- **思考段**：🧠 思考 N 次——每段独立条目，点开看思考过程，收起省空间。
- **执行抽屉**：💻 执行 ListAgents×1 Grep×3 这类胶囊——同名工具自动合并计数，点开看每次调用的参数与结果。
- **识图卡**：AI 看图（识图会话代读）的过程与结论是一张**折叠卡**，与思考/执行卡同风格——卡头显示序号、提示词摘要、状态徽章（进行中/已回传/失败）；点开看**完整提示词 + 回传全文**，按发生顺序排序，回放历史会话同样还原。
- **协作回传**：委托给子代理/别的会话干的活，回传行带来源标注；干不成（进程死了等）会标红定格，不会出现假的「等待协作回传」永远转圈。
- **假消息过滤**：CLI 内部注入的机器标注（图片回显标注、技能文档等）**不会**混进对话流冒充你或 AI 说的话。
- **代码块**：语法高亮 + 一键复制。
- **上下文用量环**：底部 ⭕ 实时显示当前会话 token 用量百分比（压缩后自动归零重计）。
- **压缩分割线**：上下文快满时 Claude 自动压缩，流里会出现「自动压缩完成 · 压缩前约 N K tokens · 用时 X」的分割线，压缩前后的会话都完整保留。
- **超长会话**：正常模式保留最近 300 条可翻；更早的进「📖 只读模式」全量查阅（仍可展开思考/工具）。

### 7.4 模型与识图

- **切模型**：底部模型 chip（或输入 `/model`）——会话内切换即时生效、上下文保留。列表来自当前配置方案的模型映射，**多模态模型带 👁**。
- **[1M] 后缀**：同一模型带 `[1M]` = 百万级上下文版本，塞长日志/大文档用它。
- **多模态直读**：当前模型本身能看图（👁 标记）时，图片直接给它读，不绕识图。
- **识图会话**：模型不能看图时，后台常驻一个专用多模态会话代你看图——主会话把图片路径交给它，结论自动回传到对话里（就是 7.3 说的识图卡），完成时右下角弹泡提示。
  - 左侧「👁 识图会话」配置：开关、模型、提示词、**多模态模型名单**（👁 标记以此为准）；
  - **🔍 检测识图模型能否读图**：拿不准网关模型是否多模态，点一下——发张测试图让它读，答对自动进名单；
  - 名单支持前缀匹配：填 `glm-5.3-flash` 即同时覆盖 `glm-5.3-flash[1M]`。

### 7.5 交互式提问（选项卡片）

AI 需要你拍板时（「方案 A 还是 B」），会在消息流里弹出**可点选的选项卡片**，点选提交后 AI 继续干活——不用打字回复。超时不答时 AI 会说明情况等你输入。

### 7.6 斜杠命令

输入 `/` 弹命令菜单。内建命令本地执行（不进对话）：

| 命令 | 作用 |
|------|------|
| `/help` | 内建命令一览 + headless 不可用的 CLI 命令说明 |
| `/model` | 打开模型菜单；`/model 名` 直接切换（模糊匹配） |
| `/mcp` | MCP 服务器列表与连接状态（代跑 `claude mcp list`） |
| `/status` | 会话状态与上下文用量 |
| `/clear` | 新建会话（原会话保留可切回） |
| `/compact` | 压缩说明（headless 走自动压缩） |
| `/exit` | 退出 claude 进程（会话保留，发送自动恢复） |

其余 `/xxx`（技能、项目自定义命令）照常发送给 Claude。

### 7.7 诊断（ⓘ）

会话面板的 ⓘ 按钮打开**诊断弹窗**：首行固定显示程序版本号，下面是最近 60 条内部运行日志（SSE 断连、重渲、队列泵动作等）。界面行为不对劲时，先看这里再反馈，一眼定位。

## 八、Claude API 配置与配置方案（设置 → API 配置）

面向「多套网关配置来回切」的场景，**配置方案在最上面**（最常用）：

### 8.1 配置方案

- 每个方案是 `~/.claude/settings.json` 的**完整快照**（Token、网关、模型映射、上下文窗口全套），一键切换整份写回——已开着的会话进程不变，新会话起效。
- **＋ 新建配置**：表单全部清空，从零填一套；「保存为新方案」一步完成写入 + 存档。
- **💾 存当前为方案**：把当前 settings.json 存成方案（同名覆盖）。

### 8.2 API 配置表单

| 项 | 说明 |
|----|------|
| **API Token** | 默认显示掩码（`f5aa6dc7…AO7e`），点 👁 眼睛显示/隐藏完整值（SSH 密码框同款） |
| **BASE_URL** | 网关地址（智谱/lanz/中转站…），随方案切换 |
| **🔍 获取模型** | 按 BASE_URL + Token 向网关拉取可用模型列表（OpenAI 兼容 / Anthropic 兼容鉴权都自动试）——成功后模型映射**每档都能下拉选** |
| **模型映射** | 5 个角色档（Sonnet / Opus / Fable / Haiku / 子代理）+ 默认兜底，竖向排布一行一档。档位是「模型别名」：名字不代表型号，网关没有 Opus 就把最强模型填 Opus 档。每档带 **1M 开关**（给模型名加/去 `[1M]` 后缀） |
| **上下文窗口与自动压缩** | 压缩窗口 / 最大上下文 / 压缩阈值% 三项竖排，决定「用到多少 tokens 才自动压缩」，一般不动 |
| **📥 导入 MobaXterm ini** | 把 MobaXterm.ini 的 `[Colors]` 段粘贴进来解析——这是**自定义主题**的快捷入口（见 9.1） |

> 打开 settings.json / 恢复 Claude 默认配置的按钮在表单最下面。

## 九、设置与外观

### 9.1 外观（换肤）

- **内置主题**：暗色系（深空蓝/夜暮紫/暖夜灰/暗调绿/琥珀暖/青瓷蓝/玫瑰暮/**德科拉**+自定义）与亮色系（午夜纸/晨雾蓝/薄荷青/暖杏/藤萝紫/樱粉/鼠尾草/晴空蓝+自定义）**两列并排**一览，数量对齐。
- **自定义主题**：暗色/亮色各一个入口，点开即以当前主题为底板的调色面板——13 个核心颜色实时预览（壳体/面板/卡片/文字/强调/终端），「亮色模式」开关决定终端浅底深字。

## 十、Claude Proxy（顶栏「Proxy」）

内网 Claude Code 的**流量管家**，一条链路三层加成：

```
Claude Code → headroom(8787 压缩) → 重试代理(37349) → lanz 内网网关
```

- **重试代理**：429/5xx/网络抖动自动阶梯重试（指数退避 + 抖动），Claude Code 不再被限流打断。
- **headroom 压缩**：上下文压缩省 token。三档可切——**完整压缩**（ML，省最多，吃 ~570MB 内存）/ **轻量压缩**（仅结构化，省 ~400MB）/ **关闭**（不启动，直接走重试代理）。CCR 流压缩更省但激进，`/compact` 可能卡死，不确定别开。
- **Lanz 额度**：登录内网 SSO 后显示今日内外用量、三模型明细、剩余/已耗积分，10 分钟自动刷新。
- **统计**：请求数/成功率/重试/失败、输入输出 tokens、免费/收费分档、最近请求列表（429 重试过的标黄）。
- **模式切换**：代理模式 ↔ 直连模式一键切 `~/.claude/settings.json` 的 base_url（重启 Claude Code 生效）。
- **托盘**：代理运行时悬浮图标显示额度+429+运行时长；右键菜单可启停/切模式/切压缩。
- **安全兜底**：退出工具自动停代理并回滚 base_url；异常强杀后下次启动自愈切回直连——Claude Code 永远不会连不上。

> 已有老的独立 proxy 工具在跑？面板会检测到并只读展示（复用不杀），关掉老工具再点启动即可接管。

## 常见问题

**Q：点了右上角 ✕ 程序没退出？**
默认「关闭到托盘」：点 ✕ 是最小化到系统托盘（终端连接/传输都保持）。单击托盘 Claude 星形图标重新打开窗口，右键托盘图标选「退出」才是真正退出。不想要这行为：设置 → 终端设置 → 关闭行为，取消勾选保存。

**Q：粘贴没反应？**
任何程序复制的内容都能贴（走系统剪贴板）。多行内容会先弹确认框，点确定才贴。

**Q：别人连不上我连着的 Telnet 设备？**
多数嵌入式设备的 telnet 服务只支持一个会话，你占着别人就进不来——这是设备固件限制，断开你的连接即可。

**Q：终端字号调不了？**
焦点要在终端里，按 `Ctrl + =`（放大）或 `Ctrl + -`（缩小）。也可在设置→终端设置里调。

**Q：工具改了没生效？**
源码运行时改文件要重启工具才加载新代码（快捷方式重新双击即可）。界面有缓存时强刷一次（`Ctrl+F5`）。

**Q：日志在哪？**
工具目录 `serial_logs/`（数据目录可在设置里改）。日志库弹窗里可直接打开该目录。

**Q：Claude 回复一半我把窗口切走了，会断吗？**
不会。回复在后台继续；切回来消息完整、动画和跟读位置都在（会话切换做了完整性对账）。

**Q：排队/立即发送的消息好像没发出去？**
队列有后台泵自动重试与对账，回复结束就会依序发出；彻底发不出去的会在队列条上**标红**提示，不会无声消失。

**Q：消息流里的「识图卡」是什么？**
AI 看图的流水卡：卡头是序号+提示词摘要+状态，点开是完整提示词和识图结论全文。它代读你贴的图片（当前模型不带 👁 时）。

**Q：双击 txt 没用本工具打开 / 想还原？**
设置 → 文件关联里勾选接管；被系统「打开方式」抢占时按提示去系统设置改默认应用。接管后双击文件会以最大化窗口打开。
