# 前端控制台 使用说明

> 一句话：面向**嵌入式 / 串口调试**的多功能工具箱——串口、SSH、Telnet 终端、日志分析与回放、文件编辑与对比、程序员计算器、TFTP/HTTP 传输、版本控制、Claude AI 助手，全部装在一个窗口里。
>
> 第一次用？只看「一、快速上手」就够了。

当前工具版本：**2.4.3**（设置 → 关于与升级 可查看与升级）

## 一、快速上手

1. 双击「前端控制台」快捷方式启动（或运行 `run.bat` 走源码）。
2. 点顶栏「新建连接」→ 选 **串口 / SSH / Telnet** → 填参数 → 「连接」。连上后自动开一个终端标签页，直接敲命令。
3. 需要 AI 帮忙时点顶栏「Claude」进入 **Claude 对话**；需要查说明书在 **设置 → 帮助**。

三个最常用的位置：

| 位置 | 作用 |
|---|---|
| 顶栏 | 新建连接 / 新建文件 / 打开 / 对比 / 日志库 / 笔记 / Claude / 版本 / 计算器 / 设置 |
| 左侧栏 | 打开与最近连接、文件树、全文搜索、TFTP/HFS |
| 右侧面板 | 命令库、输出感知、日志分析、Claude 会话与 MCP |

## 三、建立连接

点顶栏「新建连接」，弹窗内三选一：

### 3.1 串口

| 项 | 说明 |
|---|---|
| 端口 | 自动枚举本机串口；「↻ 刷新」重新枚举 |
| 波特率 | 9600 / 19200 / 38400 / 57600 / 115200 / 230400 / 460800 / 921600，默认 115200 |

### 3.2 SSH

| 项 | 说明 |
|---|---|
| 主机 / 端口 | 默认端口 22 |
| 用户名 | 默认 admin |
| 认证 | 密码 或 密钥文件（填私钥路径）；密码可留空，等设备提示再输 |
| 密码框 | 右侧眼睛按钮显示/隐藏明文 |

### 3.3 Telnet

主机 + 端口（默认 23），无需账号。

> 多数嵌入式设备的 telnet 只允许**一个会话**，你连着别人就进不来——这是设备固件限制，断开即可。

### 3.4 连接后的行为

- **断线自动重连**：指数退避，状态显示在终端覆盖层上；按 `R` 或点「↻ 重连」立即重试。
- **同一目标多开**：标签显示 `·2`、`·3` 序号。
- **连接失败**：弹窗内直接红字提示，不会静默关闭。

### 3.5 标签页

| 操作 | 说明 |
|---|---|
| 拖动 | 拖拽排序；可拖到溢出抽屉的胶囊前后 |
| 关闭 | `✕`；未保存文件会先确认 |
| 右键 | 对比（选择以进行对比 / 与选进行对比）、固定/取消固定、关闭 |
| 溢出 `⋮ N` | tab 太多时收进下拉，按类型分组、按最近使用排序，可组内固定/关闭 |
| 抽屉模式 | 设置里选「分组抽屉」后同类合并成胶囊，`✕` 一次关整组 |

### 3.6 最近连接

左侧栏「最近」，按类型分组（置顶 / 串口 / 文件 / SSH / Telnet）：

- 点击直接重开（SSH 带上保存的密码或密钥）；
- 右键「固定到置顶 / 取消固定」「从列表移除」；
- 未固定项上限 20 条，固定项常驻顶部。

## 四、终端操作

### 4.1 复制粘贴

| 想做什么 | 怎么做 |
|---|---|
| 复制 | 选中文字后 `Ctrl+C`（**无选中时 `Ctrl+C` 发中断信号 ^C**） |
| 粘贴 | `Ctrl+V` 或 `Shift+Insert`；`Shift+右键` 恒为粘贴 |
| 右键菜单 | `Ctrl+右键`（复制选中 / 复制全部 / 粘贴 / 查找全部 / 清屏） |
| 多行粘贴保护 | 超过 1 行或 500 字符会先弹确认框（首行预览），防误灌脚本 |

右键行为可在 **设置 → 终端设置** 改为「右键直接弹菜单」或「右键直接粘贴」。

### 4.2 工具栏

| 按钮 | 作用 |
|---|---|
| 暂停/继续 | 冻结滚屏，便于阅读 |
| 清屏 | 只清显示（历史缓冲同时清空后端） |
| ＋新日志 | 从此刻起另存一个新的日志文件 |
| `^C` / `^D` | 发送中断 / 结束信号 |
| 跳底 | `Ctrl+End` |
| 时间戳 | 新输出行首加 `[HH:MM:SS.mmm]` |

### 4.3 查找

`Ctrl+F` 打开查找分栏：

- 关键字输入框 + 排除框（`|` 分隔，支持正则）；
- 回车搜索全部，`Shift+回车` 跳下一个命中；
- 分栏可拖分隔条调整高度、可折叠。

### 4.4 其他

- **字号**：`Ctrl+=` 放大、`Ctrl+-` 缩小、`Ctrl+0` 还原（10–24px）。
- **关键词染色**：error / warning / info / success 自动分色。
- **全屏程序**：检测到 top/htop 类全屏序列时显示提示条，「退出」发 Ctrl-C。
- **向上翻历史**：后端分页加载，不会卡。
- **Claude 终端特殊**：滚轮转 PgUp/PgDn 用于翻看生成内容，不显示串口工具栏。

### 4.5 命令库（右侧面板「命令」）

- 顶部填「备注名 + 命令」→ `＋` 添加；
- 条目点击即发送到当前连接，可编辑、删除、拖拽排序；
- 「最近命令」列出本连接历史，可一键重发；
- 跨设备、跨重启保留。

## 五、左侧栏

四个分区页签：**打开 / 最近 / 文件树 / 搜索**，底部是 **TFTP/HFS** 面板。

### 5.1 打开

当前所有活动连接与已打开文件：显示类型、路径或波特率、行数/字符数、未保存标记 `*` 与橙色灯。点条目切换，`✕` 断开或关闭。

### 5.2 文件树

| 操作 | 说明 |
|---|---|
| 打开文件夹 | 工具条按钮，或直接把文件夹拖进窗口；支持多根工作区，根会记住 |
| 移除根 | 根行 `✕`（只从树里移除，不删磁盘文件） |
| 新建文件 | `Ctrl+N`，输入框出现在选中文件夹内，创建后直接打开 |
| 新建文件夹 | `Ctrl+Shift+N` |
| 全部收起 | 有展开项时收起；再次点击恢复上次展开状态 |
| 隐藏文件 | 开关 `.` 开头的隐藏文件 |
| 刷新 | 重扫所有根 |
| 键盘 | `↑↓←→` 导航、`Enter` 打开/展开、`F2` 重命名、`Del` 删除（进回收站） |
| 面包屑 | 滚动时显示当前目录，点击滚回该目录 |
| 右键菜单 | 新建文件/文件夹、打开、选择以进行对比、在资源管理器中打开、重命名、删除、复制路径/相对路径、在此文件夹中搜索、代码索引… |

### 5.3 全文搜索

输入关键字回车（ripgrep 引擎）：

| 开关 | 作用 |
|---|---|
| `Aa` | 区分大小写（默认智能大小写） |
| `\b` | 全词匹配（`ddr_rank` 不匹配 `ddr_rank_a`） |
| `.*` | 正则模式 |
| `fn` | 函数定义模式（跨 C/C++/Python/JS/Shell） |

- 范围 chip 默认「全部根」，点击可重置；文件树右键「在此文件夹中搜索」会限定范围。
- 结果按文件分组，点击命中跳行。
- 全局快捷键 `Ctrl+Alt+G` 直接唤起。

> GBK 编码文件只有纯 ASCII 关键词能命中。

### 5.4 TFTP / HFS（文件传输）

UDP 69（TFTP）+ TCP 8081（HTTP）双通道，**共用同一个目录**：

| 操作 | 说明 |
|---|---|
| 目录 | 点路径或文件夹按钮选择，也可手动输入；目录会记住为默认 |
| 启停 | 开关同时启停 TFTP + HFS |
| 端口 | `: 8081` 可点击直接改 |
| 设备拉文件 | `tftp -g -r 固件.bin <PC的IP>` |
| 设备推文件 | `tftp -p -l 抓包.log <PC的IP>` |
| HTTP 下载 | `http://<PC的IP>:8081/<文件名>`，大文件更快 |
| 传输记录 | 最近 20 条，含方向/文件/对端/进度/结果 |

> Windows 防火墙首次可能弹窗，选「允许访问」，否则设备连不进来。

## 六、右侧工具面板

### 6.1 命令

见 [4.5 命令库](#45-命令库右侧面板命令)。

### 6.2 感知

所有连接输出的实时汇总流（SSE）：

- 端口筛选 chips，点击某行跳到对应连接标签；
- 保留 200 行、显示最近 50 行，按关键字分级着色。

### 6.3 分析

对当前活动连接的缓冲区做全量扫描：

- 四张统计卡：ERROR / WARNING / INFO / SUCCESS（面板可见时每 5 秒刷新）；
- 点卡片列出最近 30 条，点条目跳转并高亮约 2.5 秒。

### 6.4 Claude

状态点 + 四个子页签：

| 子页签 | 内容 |
|---|---|
| 活跃 | 正在运行的 Claude 会话，点击切换或新建同名标签，`✎` 改备注 |
| 历史 | 历史会话，点击恢复（恢复走内嵌 CLI 终端） |
| 技能 | 已安装技能列表与计数 |
| MCP | MCP 后端状态、工具清单、最近调用记录 |

> 面板里的「Claude」子页与顶栏「Claude」进入的**对话界面**是两条通道：面板里是会话管理与 CLI 恢复，对话界面是完整聊天体验。

## 七、文件与编辑器

### 7.1 打开方式

顶栏「打开」或把文件拖进窗口，工具会自动分发：

| 文件 | 打开方式 |
|---|---|
| 小于 20MB 的文本 | Monaco 编辑器（可编辑） |
| 20–30MB | 弹窗让你选编辑器或阅读器 |
| 大于 30MB | 强制只读「阅读器」 |
| 二进制 / 混合内容 | 弹窗三选：二进制打开 / 阅读器 / 编辑器 |
| `.md` | 编辑器 + 实时预览分栏 |
| `.note` | 块编辑器（Editor.js） |
| Excel / Word / PDF / PPT | Office 查看器 |

### 7.2 编辑器

**文本 / 代码（Monaco）**

- 语法高亮、行号、小地图、内置查找；
- 工具栏：保存（`Ctrl+S`）、另存为（`Ctrl+Shift+S`）、重命名（也可双击标签标题）、搜索、大纲、语言切换；
- 状态栏可切**编码**（自动 / UTF-8 / GB2312 / GBK / GB18030 / Big5 / Latin-1）；
- 外部文件改动会被检测并提示。

**代码跳转**（需先在文件树右键「代码索引…」建索引）

| 操作 | 快捷键 |
|---|---|
| 转到定义 | `Ctrl+Click` 或 `F12` |
| 查找所有引用 | `Shift+F12` |
| 工作区符号 | `Ctrl+T` |
| 文件内符号 | `Ctrl+Shift+O` |
| 后退 / 前进 | `Alt+←` / `Alt+→`（栈上限 200，目标不可达自动跳过） |

多候选时弹面板，标注「✓编译内 / ✗未编译 / ~头文件」。以上按键均可在 **设置 → 终端设置** 重新录制。

**Markdown 预览**

- 三态下拉：同步显示 / 只显示原文 / 只显示预览；
- 预览主题独立：跟随全局 / 暗色 / 亮色 / 护眼纸色；
- 源码与预览**双向滚动同步**，分隔条可拖动；
- 预览内链一律用系统浏览器打开。

**笔记（`.note`）**

- 块编辑：标题、列表、清单、表格、图片、引用、代码块、分隔线；
- `/` 打开块菜单，`Ctrl+/` 打开块设置；
- 撤销 `Ctrl+Z`，重做 `Ctrl+Y` 或 `Ctrl+Shift+Z`（自研快照栈，上限 100 步）；
- 粘贴截图或拖图片可直接插入（存到 `files/images/`），点图片灯箱查看；
- 「链接」按钮看双链/反链与标签，「导出 .md」导出 Markdown。

### 7.3 笔记列表（顶栏「笔记」）

- 列出 `files/` 下所有笔记；
- 全库搜索（快照 `Ctrl+Alt+F`，可改键）；
- `#标签` chips 过滤、新建笔记、打开目录。

### 7.4 文件对比（顶栏「对比」）

- 双栏选择，可点选或拖入，两栏齐了才能「开始对比」；
- 文本走 Monaco DiffEditor，二进制自动切十六进制对比；
- 详见 [8.3 Diff 视图](#83-diff-视图)。

### 7.5 新建文件（顶栏「新建文件」）

下拉创建：笔记 / `.txt` / `.md` / 自定义后缀（只允许字母数字与 `-_`）。未保存前是草稿，保存后落到 `files/`。

## 八、专用查看器

### 8.1 Hex 查看器

| 能力 | 说明 |
|---|---|
| 大文件 | ≤16MB 整读可编辑；>16MB 只读，按 512KB 分块 |
| 查看方式 | hex 8/16/32/64 位、无符号十进制 8/16/32/64 位 |
| Intel HEX | 解析并可回写 |
| 灰显 00 | 开关，全局记忆 |
| 跳转 | 输入偏移（支持 `0x`）直达 |
| 搜索 | `Ctrl+F` 搜 hex 字节或文本，下一个 / 全部 |
| 编辑 | 直接键入 hex 改字节，方向键移动，`Ctrl+S` 保存 |
| 数据检视 | Binary / Bool / 整数 8–64 / 浮点 f16 bf16 f32 f64 / LEB128 / RGBA / 时间 / ASCII，可切大小端 |

### 8.2 Markdown 预览

见 [7.2](#72-编辑器) 的「Markdown 预览」。

### 8.3 Diff 视图

| 按钮 | 作用 |
|---|---|
| `⇄` | 互换 A / B |
| `▤` | 内联 / 并排切换 |
| `▲` `▼` | 上一处 / 下一处差异 |
| `↩` | 折行 |
| `⇕` | 折叠未变区域 |
| 二进制对比 | 切到 Hex 对比 |

- `F7` / `Shift+F7` 跳差异；打开即自动定位第一处；
- A 侧只读；空白差异也会标出。

**Hex 对比**：双栏字节视图，差异字节高亮并按差异块对齐；支持「只看差异」（保留真实偏移）、`▲▼` 导航、切回文本对比。

### 8.4 Office 查看器

| 类型 | 能力 |
|---|---|
| `.docx` | 渲染 + 大纲侧栏 |
| `.xlsx` / `.csv` | 可编辑网格：单元格编辑、`=` 公式（SUM/AVG/MIN/MAX/COUNT/区间）、撤销、插删行列、多 sheet、行高列宽；保存写回 `.xlsx` 并留 `.bak` |
| `.pdf` | 翻页、页码跳转、缩放、书签目录、全文搜索（命中上下条） |
| `.pptx` | 先用本机 PowerPoint 转 PDF 再走 PDF 引擎 |

- 「全功能编辑」调 OnlyOffice（未安装会给安装提示），保存写回原文件并留 `.bak`；
- 非 PDF/PPT 文件 >10MB、PPT >200MB 拒绝打开。

### 8.5 日志查看器

- 虚拟列表，GB 级日志秒开；
- 「搜索」分栏：关键字 + 排除，查找全部、跳到第 N 个命中、结果列表点击跳转；
- `⤒` 顶部 / `⤓` 底部；关键词染色。

## 九、日志库与回放

### 9.1 日志库（顶栏「日志库」）

| 功能 | 说明 |
|---|---|
| 目录 | 输入后「应用」（日志库从此读，新日志写到此）；`↺` 恢复默认；可在资源管理器打开 |
| 排序 | 时间↓/↑、名称↑/↓、大小↓（选择会记住） |
| 列表 | 只列 `serial_*.log`，显示时间与大小 |
| 每行操作 | 打开（日志查看器）、定位（资源管理器）、`▶ 回放` |

> 日志库弹窗内**没有**搜索和对比入口：搜索在日志查看器里，日志对比用顶栏「对比」选两份日志。

### 9.2 回放

`▶` 播放 / `⏸` 暂停 / `✕` 关闭；进度条可拖动 seek；倍速 4x / 2x / 1x / 0.5x；显示总时长与行数。

## 十、程序员计算器

顶栏「计算器」，单例标签页。

### 10.1 寄存器与进制

- 位宽 8/16/32/64 位，切换即截断；
- 位格按字节分组着色，MSB 在左，**点击翻转单个 bit**；
- HEX / DEC / OCT / BIN 四个输入框互相同步，支持 `0x` / `0b` / `0o` 前缀，64 位不丢精度。

### 10.2 运算

| 功能 | 说明 |
|---|---|
| 位运算 | AND / OR / XOR / NOT，带操作数框 |
| 移位 | `<<` / `>>` 用独立「位数」框 |
| Swap | 字节序互换（大小端） |
| Clear | 清零 |

### 10.3 表达式

- **HEX 程序员模式**：整数域，`+ - * / % & | ^ ~ << >>` 与括号，结果回写位格；
- **DEC 科学模式**：小数域，`^`、`sqrt / log / ln / abs`、`1/x`；结果向零截断进寄存器，完整值保留显示。

点按键盘两套布局（HEX 程序员 / DEC 科学）可切换；`⌫` 按 token 整删，`CE` 清空，`=` 求值，`±` 翻转符号。

### 10.4 时间戳换算

- 输入 Unix 秒 / 毫秒 / `0x` 时间戳，自动识别，输出本地时间 / UTC / 相对时间；
- 反向选日期时间 → 秒 / 毫秒 / HEX（1970 前按 32 位补码）；
- 「现在」取当前时间戳；点任意值即复制。

### 10.5 历史与哈希

- **历史**：每次按 `=` 自动记录（持久化，上限 50），点击回填重算，可清空。
- **文件哈希**：拖入文件或点「打开文件」，一次算出 MD5 / SHA1 / SHA256 / SHA512 / CRC32，点值即复制。

## 十一、版本控制

## 十二、Claude Harness（AI 对话）

顶栏「Claude」进入（设置里可改为内嵌 CLI 终端）。左边会话列表、右边消息流、底部输入卡，像微信一样和 Claude 聊，它在后台帮你操作串口、分析日志、改文件。

### 12.1 会话列表

| 功能 | 说明 |
|---|---|
| 新建会话 | 「✚ 新建会话」或 `/clear`；不继承上次项目目录 |
| 恢复会话 | 「⟲ 恢复会话」扫描磁盘转写，找回列表里消失的会话 |
| 搜索 | 按标题与项目目录过滤 |
| 重命名 / 删除 | 卡片上的笔 / `✕`；删除只移除元数据，`~/.claude` 转写保留，可恢复 |
| 项目分组 | 按项目目录自动分组，组头可折叠并显示会话数 |
| 并行 | 多会话各自独立进程、队列、上下文；同一时间只有一个前台视图，后台照常运行 |

会话卡片显示：标题、运行中圆点、模型名（多模态带眼睛）、API 方案名。**会话创建时的方案与当前方案不一致会标「⇄方案名」**，此时发送会被拦截，需新建会话。

空闲 15 分钟的进程会被回收，发消息时自动复活续上下文，无感。

### 12.2 输入卡

| 元素 | 说明 |
|---|---|
| 项目目录 chip | 列最近 6 个目录 + 「浏览其他目录…」 |
| 模型 chip | 会话内切换即时生效、上下文保留；多模态标「多模态」 |
| 思考档位 | 默认 / 低 / 中 / 高 / 最高（4K / 10K / 20K / 32K tokens）；**仅对新会话生效** |
| 权限 chip | 自动执行 / 变更前确认；确认态写操作前弹选项卡片 |
| 技能 chip | 点选把 `/技能名` 插入输入框 |
| 附件 | `+` 选择文件，或粘贴截图、拖文件入窗；单文件上限 20MB；图片走多模态或识图 |
| 截图 | 内置 Snipaste 式框选（箭头 / 马赛克 / 文字），确认后自动挂为附件 |
| `@` 引用 | 输入 `@` 弹文件下拉（会话目录下两层），`↑↓` 选择、`Tab`/`Enter` 插入 |
| 上下文用量环 | 悬浮看容量卡（见 12.4） |

**引用消息**：右键任意消息气泡「引用此消息」，输入卡上方出现引用条，发送时自动带上原文（最长 2000 字）。

**输入历史**：输入框为空时 `↑` 回溯、`↓` 恢复草稿（按会话隔离）。

**发送 / 停止**：空闲时 Enter 发送；生成中变 `■`，再点或按 `Esc` 停止。

### 12.3 排队

回复执行中继续输入的消息会进入**排队条**（输入卡上方）：

| 操作 | 说明 |
|---|---|
| `⠿` 拖动 | 调整发送顺序 |
| `↑` 立即 | 打断当前回复插队发送 |
| 铅笔 编辑 | 放回输入框（附件不带回） |
| `🗑` 丢弃 | 彻底移除，不会再发 |

队列存在服务端：跨重启、跨设备可见；回合结束后按序自动发送。持续失败（如超窗硬拒绝）会**标红提示**，不会无声消失。

### 12.4 消息流

| 元素 | 说明 |
|---|---|
| 回合工作区 | 每条回复一个组，组头「工作中 Ns · N 思考 · M 工具」，正文气泡始终可见 |
| 思考段 | 组内抽屉，流式滚播，显示时长；懒加载，点开才渲染 |
| 工具执行抽屉 | 工具名 / 参数摘要 / 状态徽章；点开看输出（Bash 可复制命令）；Edit 显示 diff |
| 查阅组 | 读文件、搜索类工具自动聚成一组 |
| 子代理行 | Task 行显示任务名 / 秒表 / 状态；点开右侧分屏（运行中=实况，已结束=回放） |
| ask 选项卡片 | 需要你拍板时停靠在输入卡上方，点选提交；多题用 `‹ 1/2 ›` 分页 |
| 压缩分割线 | 「正在压缩上下文 · 已 Ns · 压缩前约 XK tokens」，完成后改「上下文压缩完成」 |
| 上下文容量卡 | 悬浮用量环弹出：已用 / 窗口（百分比）、分类占比（消息 / 系统提示词 / MCP 工具，后两项标「估」）、缓存命中率、最近 tok/s、累计输出、子代理输出；生成中另标「生成中 +X（估值，不计入上方）」 |
| 消息操作 | 用户消息：复制 / 重发 / 编辑重发；AI 消息：复制；右键引用；每回合末尾「回滚」 |
| 长消息折叠 | 超长用户消息默认折叠，可展开全文 |

**上下文百分比口径**：圆环、侧栏胶囊、容量卡统一按**真实已进入上下文的 input** 计算；正在生成的 token 只在容量卡里以旁注提示（未进入上下文，不计入百分比）。≥80% 橙色、≥95% 红色。

**归档与只读模式**：主窗口只保留最近 20 轮，更早内容进「只读模式」（顶部归档条点击进入）——只读视图可查阅全部历史、切换会话但不退出只读，重发 / 编辑 / 回滚 / 发送全部被拦截，后台照常运行。

**子代理分屏**：右侧可拖宽，窄档约 30%（动态 / 目录），宽档约 50%（子代理实况 / 回放）；`✕` 收起不杀任务。

- **动态页**：会话状态、进程 todos、子代理与协作实况、最近工具、回合历史、当前文件。
- **目录**：正在运行 / 已结束两组，已结束的可回放。

### 12.5 斜杠命令

输入 `/` 弹出菜单（内建命令 + 技能），`↑↓` 选择、`Enter`/`Tab` 执行、`Esc` 关闭。

| 命令 | 作用 |

| `/help` | 内建命令一览 + headless 不可用的 CLI 命令说明 |

另有部分 CLI 交互命令（`/config`、`/permissions`、`/hooks`、`/memory`、`/agents` 等）在 headless 模式下不可用，输入后会给说明。

## 十三、Claude Proxy

内网 Claude Code 的流量管家，一条链路三层：

```
Claude Code → 压缩层（18788，可选）→ 重试代理（37349）→ 上游网关
```

### 13.1 启动与重试

- 面板「▶ 启动代理」；打开 Claude 对话时会后台自动确保就绪（30 秒未就绪回退直连）。
- **重试策略**（「重试配置」弹窗）：重试上限（0=无限）、最大重试时长、退避开关、退避封顶秒数；保存后热更。
- 已有外部实例占用端口时只展示复用，不杀。

### 13.2 上下文压缩

「压缩模式」弹窗二选一：**开启压缩 / 关闭压缩**（旧版 full/light 两档已合并为开关）。

- 开启：拉起 billion-context，就绪后自动切 base_url；失败自动回退关闭。
- 需要 Node ≥ 22 且安装 billion-context；未装时面板提供「联网下载安装」并显示进度。
- 带签名的 thinking 块不可压缩，收益主要来自子代理与工具输出。

### 13.3 Lanz 额度

- 内网 SSO 用户名/密码登录（密码可显隐）；
- 「↻ 刷新」「强制重登」（会话失效自救，不影响代理链路）「断开」（删除本地凭据）；
- 「自动刷新（10 分钟）」「自动重登」两个开关；
- 显示登录状态、上次刷新时间、额度概览（今日内外用量、总/剩余积分）、模型用量排名表。

> SSO 密码连续错误会**锁账号**；识别到锁定后自动登录会停止，需手动解锁后重登。

### 13.4 统计与用量

- **概览卡**：总请求、成功率、429/5xx、重试、失败、输入/输出 tokens、免费/收费请求数、运行时长；
- **请求历史**：时间 / 模型 / 摘要 / in / out / 耗时，异常请求标红，最多 200 行；
- **用量统计页**：按小时 / 近 7 日 / 近 30 日切换，堆叠柱状图 + 汇总卡 + 模型明细表；数据保留 180 天。

### 13.5 模式切换与安全兜底

- 「切换为代理模式 / 切换为直连模式」修改 settings 的 `ANTHROPIC_BASE_URL`，**需重启 Claude Code 或开新会话生效**；
- 退出工具自动停代理并回滚 base_url；异常强杀后下次启动自愈切回直连。

## 十四、机器人（HikLink 远程控制）

把 Claude 接进 HikLink（企业通讯工具）：手机给机器人发消息，本机执行并把结果推回。

### 14.1 配置

在左栏底部「机器人」胶囊里填 **App ID + App Secret**（每人填自己的机器人，互不影响），保存即重连；两项都清空 = 清除凭据并断开。

> 指示灯只表示机器人状态（未配置 / 凭据被拒 / 已配置未运行 / 连接中 / 在线）；用户名颜色表示账号登录状态（账号登录用于代理与额度）。

### 14.2 能做什么

- 给机器人发消息 → 在固定会话「前端小助手」执行 Claude 任务，结果分段推回（每段 1000 字）；
- 执行中继续发消息会立即回进度并**排队**（上限 50 条，超出丢最旧）；
- 发 `/stop` 终止当前任务；
- **选项卡片可桥接到手机**：按提示回 `1=2`（多选 `1=2,3`）即可提交决策。

### 14.3 限制

- 只响应机器人归属机主本人的会话与发送者，其他人的消息一律拒绝并回执；
- 使用独立固定会话，不占用也看不到你当前的前台会话；
- 手填凭据模式下不自动走 SSO 自愈，需人工重填；
- 单机只保留一个机器人实例（并发启动会互踢）。

### 15.5 外部依赖安装

- 选择或粘贴 `.fcpk` 离线资源包，重新检测；
- 依赖清单：WebView2、.NET 4.8+、Node/npm、Git、Claude Code CLI、工具 Python 依赖、OnlyOffice、codegraph；
- 勾选 = 本次安装/重装；支持「离线包安装所选」「在线安装所选」；
- Claude CLI 可单独「在线升级到新版本」。

### 15.6 数据目录

- 显示当前目录与各子目录占用；

## 十八、常见问题

**Q：点了右上角 ✕ 程序没退出？**
默认「关闭到托盘」：`✕` 只是最小化，连接、传输、Claude 会话都保持。单击托盘图标恢复窗口，右键托盘图标选「退出」才真正退出。不想要这行为：设置 → 终端设置 → 关闭行为。

**Q：粘贴没反应？**
任何程序复制的内容都能贴。多行内容会先弹确认框，点确定才贴。

**Q：别人连不上我正连着的 Telnet 设备？**
多数嵌入式设备的 telnet 只支持单会话，断开你的连接即可。

**Q：终端字号调不了？**
焦点要在终端里，`Ctrl+=` / `Ctrl+-`。也可在设置 → 终端设置里改。

**Q：改了代码没生效？**
源码运行需重启工具。界面有缓存时按 `Ctrl+F5` 强刷。

**Q：日志在哪？**
默认数据目录下 `serial_logs\`，日志库弹窗可直接打开该目录。

**Q：Claude 回复一半切换窗口会断吗？**
不会。回复在后台继续，切回来消息、思考、工具调用、滚动位置都完整。

**Q：排队/立即发送的消息好像没发出去？**
队列有后端泵自动重试与对账，回合结束依序发出；彻底发不出的会在队列条上**标红**提示。

**Q：识图卡是什么？**
AI 看图的流水卡：卡头是序号 + 提示词摘要 + 状态，点开是完整提示词与识图结论全文。当前模型本身支持看图时不会出现（直读）。

**Q：双击 txt 没用本工具打开？**
设置 → 文件关联勾选接管；若仍被系统「打开方式」抢占，去系统设置里把默认应用改成本工具。

**Q：上下文显示 96% 但 Claude 没压缩？**
圆环、胶囊、容量卡显示的百分比统一按**真实已进入上下文**的 token 计算；自动压缩按设置里的阈值（默认 90%）由 Claude Code 自己判定。容量卡里另有一行「生成中 +X（估值，不计入上方）」，那是正在生成、尚未进入上下文的 token。若长期不压缩，检查设置 → API 配置里的「压缩阈值%」与「压缩窗口」。

**Q：代理启动了但 Claude Code 没走代理？**
切模式后需要**重启 Claude Code 或开新会话**才生效。另检查面板显示的是「代理模式」还是「直连模式」。

**Q：SSO 登录提示账号被锁定？**
密码连续错误会锁 SSO 账号，通常等待约 8 分钟自动解锁；也可到 `sso.hikvision.com` 登录页点「Unlock account」。识别到锁定后自动重登会停止，避免反复锁号。

**Q：机器人收不到消息 / 一直离线？**
检查三项：App ID 与 App Secret 是否都填对；指示灯是否为「在线」；是否只有一个实例在跑（多开会互踢）。日志见数据目录下 `hiklink_bot.log`。

**Q：会话列表里的会话不见了？**
点左栏「⟲ 恢复会话」，会扫描磁盘上的转写记录找回。会话转写本工具从不删除。

**Q：工具很卡、拖动迟滞？**
可以在设置 → 外观开「性能模式」；Claude 大会话切走时会自动卸载消息流 DOM，属正常设计。
