# Electron 换壳迁移方案

- 日期：2026-11-20
- 状态：**已拍板，待开工**（方案定稿，未实施）
- 决策人：用户（可用性优先，"更多人能用好才是真的"）

---

## 0. 决策记录

| 项 | 决定 | 理由 |
|---|---|---|
| 目标形态 | Electron 壳 + Python 后端 sidecar + NSIS 安装 exe | 自带 Chromium = 环境免疫（WebView2 缺失/过旧/注册表劫持整类故障从架构上消失） |
| 加密 | **废除**（.enc / secure_boot 解密链 / fcpk 的 webview2 段退役） | 内部工具，防抄收益 < 分发摩擦；Electron asar 本就明文，加密是给"防人"付的税 |
| Cython .pyd | **保留** | 与加密解耦的独立开关：启动提速 + 基础防抄仍有效 |
| 升级通道 | **v1 手动覆盖安装**（NSIS 覆盖即升级） | 内网无更新服务器；electron-updater 挂起，待有服务器再启 |
| 迁移策略 | **换壳级**：前端 69 个 ES module 零改动，`loadURL(http://127.0.0.1:port)` | 不碰 file:// / CORS / 注入链——之前评审出的重伤级冲击项全部绕开 |

背景：2026-11-19/20 内网同事机连环故障（WebView2 离线包安装链、注册表 MIME 劫持致整页裸 HTML）最终定因后，用户拍板放弃"轻量借系统内核"路线，换"自带内核买断环境失败面"。

---

## 1. 目标架构

```
前端控制台 Setup.exe（NSIS）
├─ Electron 壳（main.js，自带 Chromium ≈180MB）
│   ├─ 拉起 Python 后端（现有 exe 的 --headless 无窗形态）
│   ├─ 轮询 endpoint.json / /api/status 就绪 → BrowserWindow.loadURL(http://127.0.0.1:port)
│   ├─ frame:false 原生无边框 + 自绘窗控三钮（前端 win-controls.js 逻辑平移）
│   └─ 单实例锁：app.requestSingleInstanceLock（替代 Win32 Global mutex）
├─ Python 后端（现有打包链原样：PyInstaller + Cython .pyd）
│   ├─ Flask API / SSE / 串口 / SSH / 终端 / harness 全不动
│   └─ 新增 --headless 启动参数：跳过 pywebview、只起服务、托盘可选
└─ web/（明文；extraResources 目录直带——见 P1 决策点）
```

## 2. 分期计划（总计约 5-8 工作日，串行 P0→P4，P3 可与 P2 并行）

### P0 换壳 PoC（1-2 天）——先证明壳能跑

| 任务 | 说明 |
|---|---|
| `electron/main.js` 骨架 | spawn 后端 exe → 轮询 `/api/status` 就绪（复用 endpoint.json；超时弹原生错误框含后端日志路径）→ 开窗 loadURL；后端退出 → 壳退出（树杀） |
| 后端 `--headless` 入口 | main.py 增参数：跳过窗口语义/托盘可选保留；服务链路与现有完全一致 |
| 首批验流 | harness 建会话/发消息、终端 tab、文件树、设置页 |
| 暂不做 | 无边框/窗控/网页 tab/安装包（PoC 用默认带框窗口） |

**出口判据**：四条链在 Electron 壳里全通。窗体丑没关系。
**里程碑动作**：P0 完即发内网试用（能用的丑版本），同事机提前当验收环境。

### P1 打包与拆除（1-2 天）

| 任务 | 说明 |
|---|---|
| electron-builder + NSIS | 产出 Setup.exe；图标/许可页/安装目录；oneClick:false 允许选路径 |
| **决策点：web/ 放哪** | **A（推荐）extraResources 明文目录**：Flask 直 serve，改动最小。B asar 内：需壳内静态服务或后端从 asar 读，多一跳无收益 |
| 加密链拆除 | build.py 删 encrypt_pkg 调用；secure_boot 解密路径短路；spec datas 直带明文 web/；fcpk 保留其余段（node/git/claude/pydeps） |
| 闸门瘦身 | res_boot 硬闸门删 webview2 项（.NET 4.8 保留——pythonnet 仍需）；_ensure_webview2 整段退役 |
| 删除清单（顺手清账） | MIME 钉死、_fc_wndproc / NCCALCSIZE / 边缘让位 / 黑边修复链（main.py 窗体战争 ≈1500 行）、pywebview 拖拽桥 |

**出口判据**：干净 Windows 机器（无 WebView2 / 注册表被劫持）装 Setup.exe 直接可用。

### P2 窗体收尾（1 天）

- `frame:false`：win-controls.js 改造——拖拽区换 Electron 原生 `-webkit-app-region:drag`（删 mousemove 逐帧 JS 桥）；三钮走 IPC（win.minimize/maximize/close）；最大化状态经 IPC 事件推（替代 _hgWinState 探询）
- 托盘：Electron Tray API 平移现有菜单（含 Lanzi 段）
- 窗口位置/尺寸记忆：Electron bounds 持久化替代自研
- 关闭到托盘/退出链：close 事件拦截 → IPC 问后端 → 复用 _do_real_cleanup

### P3 网页 tab 重写（2-3 天，唯一的大头）

现状：web_tabs.py（1378 行）在 WinForms 窗体里动态挂 WebView2 控件，Python 直操作控件 + ExecuteScriptAsync 推送。

目标形态：

```
Electron 主窗
└─ WebContentsView ×N（每个网页 tab 一个）
    ├─ 位置/显隐：main.js 按 IPC 消息布局（前端上报 rect → IPC → setBounds，
    │             替代 getBoundingClientRect→物理像素→Bounds 换算链）
    ├─ Python(web_tabs.py) → IPC 桥 → main.js：create/dispose/navigate/show/hide
    └─ 推送（__webTabUrl 等 12 个 window.__ 桥函数）：webContents.executeJavaScript
```

- web_tabs.py **保留全部业务逻辑**（密码库/挂起截图占位/纪元回收/防自动签到注入），仅"控件操作层"换成 IPC 调用——桥协议约 10 条消息
- NewWindowRequested → Electron `setWindowOpenHandler` 重定向
- **风险最高兼容点**：HWND 遮挡问题（密码菜单被原生窗盖住那类）在 Electron 里变成 z-order/attach 语义——行为不同但更可控，需专项验证浮层场景

### P4 收尾（0.5 天）

- 截图页回归（screenshot.html + 独立 DPI 子进程本就自包含，预期零改动）
- CDP/__consoleBuf 诊断通道：改用 webContents 直取，mcp_server 适配
- 发布流程文档：双产物（后端 exe + 壳安装包）版本对齐

## 4. 风险登记

| 风险 | 等级 | 缓解 |
|---|---|---|
| 网页 tab z-order/遮挡语义差异 | 高 | P3 单独成期 + 专项场景清单；兜底：v1 网页 tab 降级"系统浏览器打开" |
| 壳与后端生命周期竞态（退出残留/杀树不全） | 中 | 壳负责 child 树杀 + 后端 os._exit 兜底已有，P0 专项验证 |
| 包体积 +180MB、内存上涨 | 已接受 | 用户拍板：环境免疫 > 轻量 |
| 托盘/全局热键/文件关联 Win32 细节 | 低 | Electron API 成熟覆盖，逐项平移 |
| 双运行时调试复杂度 | 低 | 壳 stdout/stderr 转发进 backend_log，日志单一面板 |

## 5. 与现状的对照（为什么值得）

| 故障类别 | 现状（pywebview+WebView2） | Electron 化后 |
|---|---|---|
| WebView2 缺失/过旧 | 闸门+离线包+Fixed 探测整条链 | 架构性消失 |
| 注册表 MIME 劫持 | 进程内钉死（a674 补全） | 架构性消失 |
| 无题窗黑边/闪烁/拖拽漂移 | 两个月窗体战争（a596→a670） | Electron 原生 frame:false |
| 源码防抄 | .enc（防君子级） | asar 明文 + 保留 .pyd 机器码层 |

（对照结论：换壳买到"永不坏"；源码暴露程度上升一档，以 .pyd 保留 + 内部工具属性对冲。）
