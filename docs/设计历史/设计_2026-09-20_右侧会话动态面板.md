## 1. 信息架构（分区总表）

面板标题「会话动态」（v2.31 已定），内容区竖向 6 个分区卡片，自上而下按「稳定 → 易变 → 历史」排序（越往下变化越频繁，滚动阅读习惯）：

| # | 分区 | 内容一句话 | 级别 | 高度策略 |
|---|---|---|---|---|
| A | 会话状态区 | 当前会话：运行态 + 模型/思考/权限/三角色/目录/上下文占用 | **P0** | 固定（~7 行 kv，不滚动） |
| B | 任务进度区 | 任务 N/M + 进度条 + 完整清单（三态） | **P0**（现有增强） | 自适应，超 8 项区内滚动 |
| C | 子代理实况区 | 运行中（计时/全描述）+ 已完成（耗时/结果摘要）+ 失败态；可展开 | **P0**（现有增强）+ P1 展开 | 自适应，超 6 条区内滚动 |
| D | 当前回合区 | 本回合状态词 + 计时 + 本轮工具计数 + 结束态 | **P1** | 固定 2-3 行 |
| E | 工具活动流 | 最近 20 条工具调用（中文名+目标+耗时+三态），点击跳聊天流 | **P1** | 固定高 ~200px 区内滚动 |
| F | 回合历史 | 最近 N(≤10) 回合：耗时 / 结束态 / 工具数 | **P2** | 折叠态一行，展开列表 |
| G | 当前文件 | 最近读/写的文件路径（活动流派生） | **P2** | 2-3 行 |

### 窄面板（312px 可用宽）取舍

- **用户定调式取舍**：面板是「监视器」不是「操作台」——所有点击只做「展开详情 / 跳转锚点 / 复制」三件事，不放任何会改变会话状态的操作（发送/停止/切模型仍在输入卡，面板不重复入口）
- 单行 kv 布局（label 左 52px + 值右弹性截断），值超长 ellipsis + title 悬浮全文；不采用两列网格（340px 下两列每列 ~150px 放不下模型名如 `glm-5.3[1M]`）
- 任务清单/子代理**不用**表格，用行式列表（与聊天流工具行同构）
- 会话状态区不显示金额（v2.3 问题4 用户定调：上下文环替代金额，全应用一致）
- E 活动流是唯一必须限高的滚动列表（上限 20 条，见 §7-3）；B/C 超限走「区内 max-height + overflow」，避免整个面板双层滚动

## 5. 状态生命周期（切会话 / 切 tab / 关 tab 重建路径）

> 面板是**静态节点 + 派生数据**架构：面板本身不持有状态机，一切从 `_HG` + sessions + localStorage 派生。这是对 §7-2 快照机制的让位设计。

| 场景 | 现有路径 | 面板行为 |
|---|---|---|
| 切入 harness tab | switchTab 包装器 L4321 `_hgPanelMode(isHg)` | class 切换不变；新增 `_hgDynRender()` 全量刷一次（含拉 roles） |
| 切出 harness tab | 同上（`_hgPanelMode(false)`） | 面板 display:none（CSS 已有）；**秒表/计时 interval 不销毁但空转守卫跳过**（§7-3） |
| busy 时切出 | flow 快照**不卸载**（L4311 判 busy） | 事件继续流入，面板数据照常更新（不可见），切回即最新 |
| 切会话 switchTo | L2479 `_HG.todos=null; _HG.agents=null` | 保持；新增：清回合 ring buffer / 活动流 / todoSeen（`_HG.dyn` 一并置 null）；回放后 renderSideStatus 重建 todos（L2322 已有） |
| 关 harness tab | `_harnessClose` L4356 `_hgPanelMode(false)` | 保持（面板回到工具面板原样，动态数据留在 _HG 但不可见；重开 tab 时新 _HG 全新） |
| 页面刷新 | index.html 静态节点重建 | roles/ctx(sessions 恢复路径) 重拉；todos 由 transcript 回放重建（已有）；agents/活动流为空（可接受——瞬时态，无持久化价值） |

## 6. 更新时机与渲染策略（防抖动）

- **事件驱动**（tool_use/tool_result/result/interrupted/exit/switchTo/roles 开关）→ `_hgDynRender()`：按区 diff——各分区独立 `innerHTML` 重建，空区置 `hidden`；一秒内多次事件合并为一个 rAF（微节流，tool_use 风暴时（并行多工具）不逐条刷）
- **秒表**（唯一 interval，1s）：只更新 `[data-t0]` 计时文本与回合计时文本（textContent，不重建 DOM）——沿用现有 L2896-2901 模式，守卫增加 `document.hidden` 跳过
- **轮询**：不新增。busy 纠偏（5s sessions）与 ctx（5s）轮询已存在，它们的回调尾部各挂一次 `_hgDynRender('stat')` 分区刷新即可

## 7. 硬约束兼容清单（实施时逐条对照）

1. **零后端改动**：P0/P1/P2 全部仅动 `web/js/claude-harness.js`、`web/style.css`、`web/index.html`（面板骨架）。无新增接口；roles/ctx/sessions/events 全部复用现有。若未来 P2 需要「回合历史跨刷新持久化」，最小接口设想：`GET /api/harness/turns?sid=`（后端从 jsonl result 行聚合）——**本期不做**，前端 ring buffer 已够。
2. **flow DOM 快照机制不可破坏**：面板 DOM 全部在 index.html 静态 `.hg-dyn-pane` 内，**永不插入 flow**；跳转锚点只读 `rowById` + `scrollIntoView`（只读操作，不碰快照字符串）；展开卡插在面板分区内，与 flow 无关。busy 切出不卸载快照的现有行为不受影响。
3. **性能**：E 活动流 ring buffer 硬上限 20 条（溢出 shift，DOM 同步删首行）；B/C 区内 `max-height` 滚动；唯一 1s interval 只改 textContent 且守卫 `hg-mode 可见 && !document.hidden`；`_hgDynRender` rAF 合并；不监听 flow 的 MutationObserver（明确否决——大会话下开销不可控）。
4. **面板节点静态性**：`.hg-dyn-sec` 骨架由 index.html 提供（v2.30 实测教训：挂 harness wrap 内 q() 扑空导致面板永不显示——静态节点是根治疗法，不得回退）；动态行由 JS 填入各 sec 容器。
5. **中断/回合终结收尾一致性（含现有缺口修复，P0-1）**：
   - **现有缺口（已核实）**：SSE `interrupted`（L2243）/`exit`（L2248）分支只做 endThinking/visionSweep/grpFinalize/renderExit/setBusy，**没有 sweep `_HG.agents`**——用户点 ■ 停止时子代理永远显示「运行中」+计时狂跳。P0-1：这两分支补上与 result 分支（L2192-2197）相同的 sweep（标记 done + doneAt=now + err 标「已中断」）。
   - 换装开关 `_hgPanelMode` 必须保持**顶层函数**（v2.31 实测教训：闭包内定义 + 顶层调用 = ReferenceError 全炸）；`renderSideStatus` 同理收敛为闭包内唯一入口、顶层不引用。
   - 面板渲染幂等：`_hgDynRender` 可被任意事件重复调用无副作用（全量派生，无中间态）。
6. **中文名与并行**：`_AGENT_LABEL` 沿用（executor=执行者/coder=编程者/designer=设计者/general-purpose=通用子代理，未知回退原 type）；`_HG.agents` 是 map，并行多子代理各自独立条目按 t0 排序，计时互不串（每行独立 data-t0，秒表按行更新——现有模式已支持）。
7. **双状态来源口径**：模型/思考/权限一律「当前会话值（sessions 条目）优先，无会话回退新会话参数（_HG.*）」，与输入卡 chip 的「对新会话生效」语义区分，面板 tooltip 注明归属，防用户误读（chip 改的是下一条会话，面板显示的是本会话）。
