## 当前已覆盖

- 顶层整页、用户名 + 密码同页的普通登录。
- 点密码框 → 弹出该 origin 已存账号 → 选中才填充；不自动回填、不自动提交。
- 登录提交后只问“是否保存密码”；保存走工具内部 `safeStorage`/DPAPI。
- 所有网页 tab 共用 `persist:webtabs`，SSO 登录一次后业务应用的 cookie 共享。
- 🔑 当前站点菜单：填充 / 显示 / 删除；删除确认是工具自绘弹层。

## 公司环境验收 / 补做

- [ ] **顶层单页 SSO**：按现有流程走一遍，确认点框候选、填充、保存提示都正常。
- [ ] **SSO cookie 共享**：SSO 登录后新开业务应用 tab，确认无需二次登录；
      记录 cookie 有效期/过期后的表现。
- [ ] **两步登录**（先用户名、下一页密码）：
  - [ ] 记录该 SSO origin 最近输入的用户名；
  - [ ] 用户名步骤点输入框能否弹已存账号；
  - [ ] 密码步骤保存时 user 不能为空，下一轮能回填两步。
  - 确认是两步后只加 username memory + 用户名步骤候选，保持现有单页手感。

      frame 结构后，再决定 frame 级 CDP、顶层打开还是剪贴板兜底，不猜着写。
- [ ] **自绘 div + fetch 登录**：填充不受影响；确认保存提示是否触发；

## 部署注意

- `safeStorage`/DPAPI 绑定 Windows 用户与机器：家里保存的密码不会跟到公司
  机器，同事机器也要各自保存一次；SSO 会话 cookie 各自持久化。
- 不硬编码 hikvision 域名；SSO 页面按普通 origin 处理。
- 不做 KeePass / 主密码 / 建库卡 / 管理列表；这些已从用户路径移除。
