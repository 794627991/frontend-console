# 子代理实况窗格 UI 重设计（调研 + 设计方案）

- 日期：2026-09-21
- 触发：用户实锤两点——①「不能单独关闭某个选项卡」；②窗格内容是原始文本流「这里的 UI 需要大修」。
- 性质：设计稿。实施分期见 §5，确认后按期推进。

## 1. 现状调研（全部带代码证据）

### 1.1 结构
```
.hg-subpane（与主聊天列平级的右列，默认隐藏）
 ├ .hg-sub-resizer        拖宽条（220-640px，localStorage 持久化）
 └ .hg-sub-wrap
    ├ .hg-sub-head
    │  ├ .hg-sub-tabs     tab 条（_subTabsPaint innerHTML 全量重绘）
    │  └ .hg-sub-x        窗格级唯一 ✕（只隐藏整窗，不清任何 tab）
    └ .hg-sub-body
       └ .hg-sub-msgs ×N  每个 tab 一个内容容器（dataset.tid），display 切换
```
状态对象 `_sub = {tabs, order, active, manual}`；超 6 个 tab 静默淘汰最旧（内容一并丢）。

### 1.2 问题一实锤：无法单独关闭 tab
- `_subTabsPaint` 生成的 tab 模板**根本没有每-tab ✕ 元素**——不是事件 bug，是 UI 不存在。
- 唯一的 ✕ 是窗格级：只 `display:none` 整窗，tabs/内容原地保留。
- 单 tab 移除函数 `_subDrop(tid)` **存在但没接任何 UI**（仅程序内部调用：协作包装清理、6-tab 淘汰）。
- 附带发现：6-tab 淘汰是静默的，被淘汰内容无法从窗格找回（只能靠面板回放按钮）。

### 1.3 问题二实锤：窗格内容是玩具级文本流
- 内容行三类：`hg-sub-msg`（12px 纯文本 pre-wrap）、`hg-sub-tool`（10.5px mono 单行省略）、`hg-sub-res`（结果摘要 120 字）。
- **markdown 完全没渲染**（纯 esc）——子代理的中间结论是 markdown（含代码块），全部以裸文本显示；主 flow 现成的 renderMd/mdBubble/codeBlockEnhance（语言标签+复制钮+hljs）一点没用上。
- **thinking 块不进窗格**（只进主 flow 思考抽屉）——窗格里子代理"在想什么"完全不可见。
- **200 行硬上限静默删首**，无「已省略」提示。
- 无头像/模型徽章（回放路径有、实况路径没有——同一窗格两套形态不一致）。
- 无自动滚动跟随判定（display:none 期间也无补偿）。

### 1.4 可复用积木（主 flow 已验证）
`renderMd`/`mdBubble`（markdown+链接拦截）、`codeBlockEnhance`（hg-code 容器）、`renderToolUse` 的 collapsible 工具行（图标/着色/秒表槽）、`_hgAvaCls` 头像色板、回放路径的头像+模型徽章行。
两条铁律（主 flow 踩坑总结）：快照保真必须 dataset 可序列化 + 事件全走委托绑定（直绑监听随 innerHTML 重建丢失）。

### 1.5 生命周期边界
- 切主 tab：窗格随 wrap 隐藏，状态保留（SSE 照常流入累积）。
- 切会话：`_subReset` 全清（窗格不进快照）——保持现状（主 flow 是唯一持久记录处，窗格定位是实时镜像+回放入口）。
- 回合终结：非手动开的窗格自动收起；手动开的保持。

## 2. 设计目标
1. 每个窗格 tab 可独立关闭，运行中代理关闭后可随时从面板/主 flow 行重开。
2. 窗格内容从「原始文本镜像」升级为「结构化迷你消息流」：markdown 渲染、代码高亮、图标化工具行、思考可见。
3. 零静默丢失：裁剪有提示、运行中关 tab 有去向说明。
4. 全部走主 flow 已验证的积木与两条铁律，不发明新轮子。

## 3. 信息架构（重设计后的窗格）

### 3.1 tab 条
```
[● 审核 · reviewer  ✕] [● 开发 · dev  ✕] [▣ 回放 · 历史  ✕]        [✕]
   状态点+中文名          hover 浮现单-tab ✕        回放徽章        窗格级 ✕（保留）
```
- 单-tab ✕：hover 浮现（运行中常隐避免误触，hover 提示「关闭视图（任务继续在后台跑）」）。
- 点击 → `_subDrop(tid)`（已有函数接 UI）：删该 tab+内容缓存；运行中代理的档案不动，面板行/主 flow 行可随时重开。
- 关闭当前激活 tab → 自动激活 order 中相邻 tab；全关 → 窗格收起。
- tab 溢出（>6）从静默淘汰改为：最旧非 pin tab 关闭时窗格内闪一条 banner 提示（后续可做 pin）。

### 3.2 窗格体：结构化迷你消息流
```
┌────────────────────────────┐
│ [G] glm-5.3-flash · 后台    │  ← 头像+模型徽章行（对齐回放路径，实况补齐）
│ ▸ 💭 思考 · 12s             │  ← thinking 折叠行（新增，点开懒渲染）
│ ⚡ Bash · git log --oneline │  ← 工具行（图标+摘要+状态点，点击展开输出）
│   ↳ 成功 · 13 行提交记录     │
│ [G] 中间结论 markdown……     │  ← mdBubble 渲染（代码块带高亮+复制）
│ ⚡ Read · src/snip.py       │
│   ↳ 成功                    │
│ ⬆ 已省略最早 47 行           │  ← 裁剪提示条（替代静默删首）
│ …（贴底自动跟随）            │
└────────────────────────────┘
```
- 文本行：`mdBubble`（markdown-it+hljs）——子代理输出是 markdown，渲染质量对齐主 flow。
- thinking：新行类型 `hg-sub-think`（折叠，点击懒渲染正文——子代理 thinking 量大，默认收起防淹）。
- 工具行：样式升级（图标+状态点+耗时），结果行可点击展开全文（>120 字不再截死）。
- 裁剪：保持 200 行窗口，删首时若首条非提示条则插「⬆ 已省略 N 行」一次（计数累进，不重复插）。
- 自动滚动：仅视口贴底（≤80px）时跟随新内容；用户上翻查看历史时不拽人。
- 实况与回放同一套行渲染（回放的 avatar+徽章行推广到实况），消除两套形态。

### 3.3 状态与文案
- 运行中关 tab：toast「已关闭视图——任务继续后台运行，可在面板子代理区重新打开」。
- tab 徽章补齐：运行中绿点脉冲（现状保留）+ 完成后 ✓/✗ 落在 tab 上（现有 err 类扩展 done 类）。

## 4. 技术要点（实施约束）
- 单-tab ✕ 与行点击都要走**事件委托**（tab 条 onclick 已有，扩 closest('[data-hg-subclose]') 分支 + stopPropagation 防激活）。
- md 渲染成本：子代理输出逐块 renderMd，长会话下与主 flow 同量级（可接受）；代码高亮沿用 hljs（不做懒高亮，窗格视口小）。
- thinking 进窗格需 `_subFeed` 增喂 thinking 块（现在只喂 text/tool_use）——数据源已有，纯前端改动。
- 不动：窗格定位（实时镜像+回放入口）、切会话清空、manual 语义、6-tab 上限（只加提示）。

## 5. 实施分期
- **P1（本轮，预计 ~120 行）**：单-tab ✕（接 _subDrop）+ 关闭 toast + 窗格体 md 渲染（文本行换 mdBubble）+ 裁剪提示条 + 贴底跟随。
- **P2（下一轮）**：thinking 折叠行进窗格 + 工具行图标/状态点升级 + 结果行展开全文 + 实况补头像徽章。
- **P3（远期，可选）**：tab pin、窗格分栏多开、子代理用量曲线。

## 6. 验收清单
- [ ] 任意 tab 可单独 ✕，其余 tab 与运行中代理不受影响
- [ ] 关闭运行中代理的 tab 出提示；面板/主 flow 行可重开
- [ ] 窗格内 markdown/代码块正常渲染（高亮+复制钮）
- [ ] 超 200 行出现「已省略 N 行」提示而非静默消失
- [ ] 贴底自动跟随；上翻查看时不被拽走
- [ ] 切主 tab/切会话/关 harness tab 行为与现状一致（回归）
